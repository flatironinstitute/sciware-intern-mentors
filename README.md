## Learning Objectives
The Sciware team has defined computing-related learning objectives and desired outcomes for the 
Summer at Simons internship program in order to provide more structure to the summer programming 
and help assess the success of our educational efforts. The intention of these objectives is to 
encourage intern-mentor teams to engage in topics related to  computational skills and to 
provide structure, not to add additional requirements to the program. The objectives and 
desired outcomes detailed below are intended to be optional and aspirational for the interns, 
and not required.

By the end of the summer, we hope that every intern can: 

1. Name the tool(s) used to edit code (aka IDE). <br>
   Examples: VS Code, vim, emacs

2. Name any AI tools and/or models used. <br>
   Examples: chatGPT web, GitHub Copilot, Claude, Gemini

4. Name programming languages and notable packages and dependencies used.<br>
   Examples: Python, numpy, astropy, C++, R

5. Name the tools used for environment and/or package management.<br>
   Examples: conda, uv, pixi

6. If the cluster was used, measure how many CPU and GPU hours were used.

7. Create a GitHub repository containing new material developed.

In addition, every intern’s posters will have a small box dedicated to reporting on these objectives.
